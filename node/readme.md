   # retrival Phase

   We used text-embedding-3-large while indexing, but text-embedding-3-small during retrieval. Why doesn't that cause a problem?
   => The query vector and the stored vectors should come from the same embedding model. Different models produce vectors in different embedding spaces (and may even have different dimensions). Similarity search only works correctly when both document embeddings and query embeddings are generated by the same model.

So your retrieval code should also use:

const text_embeddings = new OpenAIEmbeddings({
    model: "text-embedding-3-large"
});
